At 021 OÜ in Tallinn I worked as a **Frontend Software Engineer** from July 2022
to June 2023, building complex, data-intensive UI components and visualisations
for the Cardano blockchain pool.

IntoCardano mission is to help Cardano to reach its beautiful goal - to be the first really decentralized network in the world in order to update worlds systems. By enlightening, showing and educating people about Crypto and Cardano in particular. 

The visualisation work leaned on **D3.js** and advanced CSS — the kind of
interface where the data volume, not the layout, is what makes it hard. I also
integrated and maintained a local UI library through **Storybook**, standardising
components so design stayed consistent as the application grew.

## Stack

Next.js, MobX, D3, GraphQL, Storybook and SCSS on the frontend; Node.js with
TypeScript and Express on the server.
